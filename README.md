# SoftwareFactory

SoftwareFactory è una factory AI local-first per progettare, generare, verificare e versionare applicazioni. Ispirata all'orchestrazione di [BookWriter](https://github.com/KeyserDSoze/BookWriter).

Questo repository contiene la SPA React/TypeScript e il generatore di scheletri applicativi configurabili.

Per iniziare: `cd src/frontend && npm install && npm run dev`.

Vedi `docs/architecture.md` per le decisioni architetturali.
